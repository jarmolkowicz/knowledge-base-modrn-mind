# Preview and approve before publishing

Title is editorial, not a validated named method.

## Use When

AI helps produce a public video, presentation or other artifact.

## Try It

1. Define the message and factual claims needing checks.
2. Request an inspectable draft or preview before final rendering or release.
3. Review the actual artifact: claims, captions, voice, cuts and evidence. [Inference] Open original sources rather than trusting agent-captured proof alone. Review corrections before approving release.
