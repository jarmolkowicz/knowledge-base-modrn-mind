# Curate context and clarify before drafting

## Use When

The assistant is guessing because the task depends on local goals, examples or constraints.

## Try It

1. Select relevant background, project material and examples. Distinguish references from intended outputs.
2. Ask AI to read, identify gaps and ask questions before proposing a plan.
3. Answer questions, correct the plan, and review final work against the original context and purpose.

## Limits

Read-only prompts do not enforce access control. Extra personal context can expose data and add noise. Files go stale; assistants can overlook contradictions.
