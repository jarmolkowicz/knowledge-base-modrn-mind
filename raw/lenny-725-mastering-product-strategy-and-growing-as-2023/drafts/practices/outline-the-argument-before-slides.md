# Outline the argument before making slides

## Use When

Deck formatting is consuming attention before the message is clear.

## Try It

1. Write the argument as an outline.
2. Sketch boxes for slides and write their headline text.
3. Check that the headlines form a coherent sequence.
4. Sketch supporting visuals, then build the slides.

**[Inference] Editorial adaptation / boundary:** Use an accessible low-fidelity medium. If AI later formats slides, compare them with the argument you chose.
